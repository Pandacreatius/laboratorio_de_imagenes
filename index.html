La regla de esta página

Cada bloque tiene una vista previa dentro de una ventana independiente. Esa ventana se construye únicamente con el HTML y el CSS que aparecen al lado, usando etiquetas semánticas siempre que aportan significado al contenido.

✅
Objetivo para el alumnado: copiar el HTML, copiar el CSS, pegarlos en sus archivos index.html y estilos.css, y comprobar que el resultado coincide con la vista previa.

Casos reales de posicionamiento de imágenes

Cada ejemplo está pensado como un componente habitual de una web: imagen centrada, tarjeta, bloque lateral, hero y etiqueta superpuesta. Se evita usar divs en los ejercicios cuando existe una etiqueta semántica más adecuada.

Laboratorio final aplicado

Construye un componente real y copia su HTML/CSS

Cambia el tipo de componente, el ajuste de la imagen, la posición del recorte, la altura y el redondeado. Ahora la vista previa puede simular escritorio, tablet o móvil para que los componentes grandes no se vean encajonados.

Controles del componente

En escritorio, si la vista no cabe entera, desplázate horizontalmente dentro del recuadro de previsualización.

Recuerda: object-fit controla cómo se adapta la imagen dentro de su caja. object-position decide qué zona de la imagen queda más visible cuando se recorta. La opción de vista previa permite comprobar el mismo componente en escritorio, tablet y móvil.
